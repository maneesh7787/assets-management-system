                      INSTALLATION STEPS
═══════════════════════════════════════════════════════════════════════

1. Clone/download repository
2. Move to web server directory (htdocs/www)
3. Create MySQL database: asset_management_system
4. Import sql/schema.sql
5. (Optional) Import sql/sample_data.sql
6. Update config/config.php with database credentials
7. Update BASE_URL in config/config.php
8. Set proper file permissions (Linux/Mac)
9. Access via browser: http://localhost/assets-management-system

Detailed instructions available in INSTALLATION.md
